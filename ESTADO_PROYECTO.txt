🎯 PRÓXIMOS PASOS PARA USAR EL PROYECTO

1. INICIAR JUPYTER
   Doble clic en: start_jupyter.bat
   O ejecuta: .\start_jupyter.ps1

2. PREPARAR DATASET (Cuaderno 01)
   • Abre: 01_preparacion_dataset.ipynb
   • Cell → Run All
   • Espera ~2-3 minutos
   • Verifica: archivos .npz creados en data/

3. ENTRENAR MODELO (Cuaderno 02)
   • Abre: 02_modelado_entrenamiento_cmm.ipynb
   • Cell → Run All
   • Espera ~15-25 minutos
   • Objetivo: >80% validation accuracy
   • Verifica: modelo guardado en models/

4. PREDICCIONES (Cuaderno 03)
   • Copia imágenes JPG/PNG a: data/test_images/
   • Abre: 03_pruebas_y_predicciones.ipynb
   • Ejecuta celda de predicciones
   • Analiza resultados

5. REENTRENAMIENTO SELECTIVO (Opcional)
   Si detectas clases con accuracy <75%:
   • En cuaderno 03, ajusta: CLASSES_TO_RETRAIN = [3, 5]
   • Ejecuta celda de reentrenamiento
   • Verifica mejoras en el reporte
   • Modelo mejorado se guarda automáticamente
